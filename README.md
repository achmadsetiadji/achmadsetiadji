## About Me:

Fullstack developer based in Depok, Indonesia. I take applications from the UI down to the database: schema design, authentication, server-side logic, and the interface people actually use. Most of my recent work is internal systems for schools and small businesses — the kind of software that has to keep working every day, not just look good in a demo.

- 🏫 Currently building **SIAK SDIP AL-HAADY**, a school management system handling students, attendance, grades, and tuition payments
- 📚 Built **JurusanKu**, a decision-support tool that helps students pick a university major using the Certainty Factor method
- 🧠 Comfortable across the stack: React frontend, TypeScript, SQL, and Python for data work
